# AfriDevelopers GitHub Pages replacement

This package contains the complete AfriDevelopers website and preserves the custom domain `afridevelopers.com`.

1. Open `https://github.com/Kabogo/afrideveloperss`.
2. Upload every file and folder from this package to the repository root on the `main` branch.
3. Allow replacement of `.github/workflows/deploy.yml` when prompted.
4. Commit the upload to `main`.
5. Open **Actions** and wait for **Deploy AfriDevelopers to GitHub Pages** to finish.
6. In **Settings → Pages**, confirm **Source** is set to **GitHub Actions** and the custom domain remains `afridevelopers.com`.

Do not remove `CNAME`; it preserves the current domain.
